# Ilustraciones conceptuales de la versión 1.3

Generación mediante la herramienta integrada de imágenes (built-in imagegen); modo de generación nueva, fondo opaco. No se usó la ruta por API ni una edición de la fotografía del autor. Las figuras técnicas se dibujan desde los valores de la simulación, no desde estas imágenes.

Los tres PNG originales se conservan en `site/src/assets/`. Astro produce derivados WebP de varios anchos para las páginas. Las imágenes son metáforas visuales identificadas como ilustraciones generadas; no representan dispositivos, experimentos ni resultados reales.
