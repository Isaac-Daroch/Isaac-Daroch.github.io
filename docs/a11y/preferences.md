# Preference contract and persistence

PREF-01–06, READ-01–04. Canonical pure module: `site/src/modules/preferences/domain.mjs`. Browser mechanism: `browser.mjs`. The generator publishes those same modules under `/ui/` for Astro and Quarto; the early initializer is derived from the same pure source, not an independently edited list of allowed values.

## State

Version 2. Defaults: theme system; appearance system; colorProfile editorial; scale 1; readingMode false; font editorial; spacing normal; motion reduce; dataMode system. Enumerated options follow the owner specification exactly. Unknown or mistyped fields recover defaults; unrecognized versions do not execute input. Color or style strings from localStorage are never interpolated unchecked.

Explicit theme/appearance wins over OS theme/contrast. System contrast more→high, less→soft, custom/none→editorial; final forced colors remain controlled by the OS. Effective reduced motion is local reduce OR OS reduce. Low-data mode is a local choice or supported system signal. There are no automatic external media to download in this candidate. Reading mode, scale, font and spacing remain independent of theme/profile.

## UI and focus

`/preferences/` and `/es/preferences/` are complete nonmodal pages with fieldsets and native selects/checkboxes. There is no automatically opened modal, diagnosis questionnaire or hidden icon-only entry. A setting is applied without reload or focus jump. Reset remains focused and announces once. The initial site works without activating these controls.

## Storage

Only `isaac-visual-preferences-v2` is written. The recognized old key `isaac-grafito-visual-v1` migrates recognized fields and is removed only after successful own-key migration. No localStorage.clear is used. Parsing/read/write errors are caught. A change still applies in memory when saving is denied, with a truthful notification. The current document's in-memory state survives ordinary initialization/pageshow; a full navigation in a browser that disallows all persistence cannot magically retain memory across documents. That limitation is stated rather than claiming successful persistence.

The storage event synchronizes independent tabs; removal restores defaults. OS media changes update effective state but do not replace explicit selections. Back/forward restoration reapplies state without duplicate initialization. Tests cover corrupt JSON, write/read denial, reset preserving an unrelated key, system motion precedence and generator/language navigation.

## Privacy

No preference goes into a query parameter, analytics stream, server log intentionally generated by the application or a diagnostic profile. No screen reader or disability detection is attempted. These preferences need no account. Exported agent records are separate and not persisted automatically.
