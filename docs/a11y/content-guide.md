# Editorial publication and human validation

The catalog is not a generator of achievements. Publication status must be separate from source-verification status. `publications.json` contains the existing paper; UNAB's source confirms publication in August 2026 and the listed authors/DOI. The verification date concerns that record, not experimental replication. No public clinical repository, video, PDF or extra publications are inferred. Preserve preprint/submitted/accepted/published distinctions and evidence dates.

Research pages provide a public explanation, technical approach, status, assumptions and limitations, then connect the actual article, protocol, software and written contact. Future summaries should be reviewed by the owner; the new summaries are editorial paraphrases for review. They are not independent scientific validation.

Events/news/media archives are empty until confirmed records exist. Schema checks enforce required provenance and dates; news must separate facts/summary from commentary. Do not substitute build time for event or publication dates. Required future media alternatives include a reviewed transcript, captions for synchronized audio/video and visual-description coverage where needed. A human-reviewed marker requires an actual reviewer; the code cannot establish quality. Structural schema tests use isolated synthetic fixtures only.

Figures need contextual alt, complex HTML descriptions, axis/unit/metric explanations, uncertainty and real tables if data are available. Do not invent numbers from pixels. World-model grids are educational diagrams, supported by protocol and chronological transcript; no research superiority is claimed. Tables use captions/scoped headings and local keyboard scrolling. Native MathML is retained; variables and source LaTeX are available. Verify with actual assistive math navigation before claiming compatibility.

No owned downloadable PDF/CV exists in the inspected source. Keep HTML background available; future PDFs require source, selectable text, language/title, tagging, reading order and human review. Publisher-site access is external and cannot be certified by this portfolio.

English published routes stay stable. Spanish entry/map/preferences are actual Spanish content; other destinations are labeled English. No fake fully translated article is offered. Scientific translations, names and alternative descriptions require human proofreading. Use local fonts and transparent sources rather than invented downloads, social links or audiences.
