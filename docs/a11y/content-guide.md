# Editorial and scientific content guide

IA-01–03, DATA-01–02, SCI-01–06, MEDIA-01–03, LANG-01, GOV-05. Content owner: Isaac Daroch. Technical validation and owner confirmation are separate. No unverified field becomes public simply because the schema accepts it.

## Source records and publication flow

1. Add a draft record to the appropriate typed collection. Preserve ID and record source, actual event/publication date, verification date and language separately.
2. Supply readable and technical explanations, results only where evidenced, limitations and source/citation/code relationships.
3. Review links, metadata, alternate text, captions and translations against primary material. A URL existing does not verify its content or authorship.
4. Mark the record approved only after editorial review; build validation refuses structurally incomplete published records. Drafts must not create public empty cards or hash-only links.
5. Run content validation, build, route checks and affected accessibility tests. Corrected text may change layout, accessible naming or scientific meaning.

## Record responsibilities

Publication: title/authors/year/status/venue/verified DOI or URL, summary, accessible explanation, related research and genuine code link if available. Distinguish authored publication from related literature and submitted/preprint/accepted/published. Do not call the site's repository the code of an unrelated clinical paper.
Research: question/problem/method/status/results/limitations/references/materials. Provide both public and technical explanations without hiding methods or uncertainty in reading mode. Self-model demonstrator results are simulator outputs, not new published findings.
Repository: actual URL, purpose/status/instructions/license only when stated, last verified date. Do not fabricate stars, license or live status.
Event: official name, public place, dates, confirmed participation role, materials and contextual image descriptions. An organizer announcement alone does not prove Isaac attended. Never publish a private future itinerary.
News: primary source where appropriate, fact date, publication date and retrieval date, factual summary separate from authored commentary. Do not attribute an AI-written view to Isaac as if he approved it.
Social: actual approved platform URL, visible platform/function, review state. Unknown YouTube/Instagram/X accounts stay unpublished.

## Audiovisual requirements

A verified video record needs title, language, original URL or file, known duration, context, references, reviewed synchronized captions where audio exists, an adjacent HTML transcript and description of essential visual information not already narrated. A transcript alone does not meet audio-description criterion1.2.5. Audio-only needs a faithful transcript including meaningful sounds; silent video needs a complete alternative. Live captions require a real capability and a rehearsal. External players load only after deliberate action and retain local context/alternative. No autoplay.

Current candidate has no supplied video/audio records or player. These conditions are not falsely marked executed. Adding media changes applicability and requires rerunning the relevant manual and automated tests before publication.

## Figures, tables, mathematics, downloads

Figures need short functional alt plus structured nearby long description for complex information. Include variables, axes, units, comparisons, uncertainty and limitations; numerical data must come from actual source records, not guessed pixels. Provide original data/table when authorized. Redundant labels/patterns replace color-only coding. Tables use captions and associated headers; narrow layout preserves table semantics.

Quarto is configured to generate MathML rather than mathematical pictures. Variables and assumptions remain nearby; actual screen-reader mathematical navigation is pending manual validation. Do not label a render configuration as a successful assistive-technology test.

Prefer HTML equivalents for CV and own materials; downloaded PDF accessibility requires its own text/tag/order/language/alt review. No CV PDF has been fabricated for this candidate. External publisher files are outside the local conformity claim and linked as such.

## Bilingual content

The root editorial site remains English; `/es/` contains actual Spanish counterparts, including controls/errors. Notebook articles remain English with explicit notice and a link to Spanish research summaries. Translations generated in this work require owner/editorial review before being described as authoritative scientific translations. No flag-only selector or false equivalent-language label is used.
