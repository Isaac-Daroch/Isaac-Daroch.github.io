# Security and privacy

No private user accounts, database, API keys, upload endpoint or inference service exist in this static product. Episodes are parsed locally with byte, depth, node, command and version limits; commands cannot execute code. A verified replay is not an authenticity signature.

Treat external dependencies, imported JSON, install archives and recovery journals as separate trust boundaries. Package integrity does not prove trusted authorship; obtain releases from the owner's repository. Do not disable system protections globally. The installer preserves .git and rejects unsafe paths rather than escalating privileges.

Do not publish .env files, tokens, backups, private photographs, student records or supplied books. Normal verification jobs have contents-read permissions only. Publication receives Pages/OIDC permissions only in the deploy job. Changes to workflows require explicit review.

Report suspected defects privately to the owner through the listed contact channel, without including credentials or personal documents. Stop publication if a release identity differs from the validated artifact. Preserve the previous build and incident logs; do not delete backups before investigating.
