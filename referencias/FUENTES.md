# Source references supplied with the specification

Current implementation consulted WCAG 2.2, Playwright accessibility testing, Quarto HTML basics, the installed Quarto 1.10.18 templates and UNAB publication source. The original consultation date below belongs to the supplied document.



# Fuentes primarias y alcance

Consulta de las referencias S01–S40: 18 de octubre de 2026. Los archivos de diseño anteriores son la fuente de los colores, no una validación médica. El estado actual de ningún repositorio se ha usado como evidencia de implementación.

WCAG es el estándar de referencia; Understanding explica criterios; APG ofrece patrones; COGA amplía la orientación cognitiva; MDN y la documentación oficial describen mecanismos y herramientas. Los valores de diseño y presupuestos del proyecto son decisiones propuestas, no mandatos de todas estas fuentes.
